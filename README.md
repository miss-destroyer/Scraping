# Scraping
I have created a mini project to scrape data from a Daraz site using Selenium library. In this code, I have used class-based structure to improve the code. I have been used WebDriverWait to handle dynamic element loading more efficiently. I have created separate functions for each task, such as searching, data scraping, and storing data in MongoDB, to make the code more organized and error-free. 
In this code, the user provides input for the product to be scraped and also specifies the database collection name, allowing them to choose a custom collection name. The scraped data is directly stored in MongoDB using dictionaries and lists.
MongoDB connection failures and insertion errors have also been handled properly. If a database collection with the same name already exists, it will not be stored again. For example, if one user scrapes a product and names the database collection, and another user scrapes the same product but provides a different collection name, the data will be stored without any errors. However, if the collection name is the same, the user will be prompted to enter a new collection name.
